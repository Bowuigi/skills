# Personal skill directory

[![skills.sh](https://skills.sh/b/bowuigi/skills)](https://skills.sh/bowuigi/skills)

They're here in case other people find them useful. Also so I can share them on work teams.

Every skill here is prefixed with `bow-` both for searchability and to avoid conflicts with other skill packs.

_Note:_ Some of the skills contain harness-specific information (e.g. experiment directories). I use OpenCode and Pi, so only those are covered.

# Installation

Run `npx skills add https://github.com/Bowuigi/Skills` and pick whichever you want.
