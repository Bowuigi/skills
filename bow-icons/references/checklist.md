# Check list

Run this list on every change that adds icons.

## Choice

- [ ] Every icon stands for one meaning that a person can read as text.
- [ ] Every icon has a familiar symbol. No icon needs a lesson to learn.
- [ ] The same icon always means the same thing in the interface.
- [ ] The interface has no icon that only repeats what the text already says.

## Layout

- [ ] Every icon has a visible label, or its control shows the name on hover, focus, or tap.
- [ ] The icons support the text. They do not compete with it.
- [ ] The icon size matches the text size.
- [ ] All icons in the interface use one style and one stroke width.
- [ ] Every icon control has a target of at least 44 by 44 pixels.

## Accessibility

- [ ] Decorative icons have no accessible name and stay hidden from screen readers.
- [ ] Every icon control has an accessible name.
- [ ] The icon and its background have a contrast of 4.5:1 or more.
- [ ] State and status do not depend on color alone.

## Delivery

- [ ] The project uses one way to ship icons. It does not mix ways.
- [ ] The code imports only the icons that it uses.
- [ ] Every icon name exists in the current icon list.
